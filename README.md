# Academic Website & CV — Dr. Humberto Bernal

This repository contains the complete personal academic website and virtual CV for **Dr. Humberto Bernal**, built in the format of [AcademicPages](https://academicpages.github.io/).

## Structure

- `index.html`: Fully self-contained, standalone interactive website. Open directly in any web browser without needing Ruby/Jekyll!
- `images/profile.jpg`: Dr. Humberto Bernal's profile photograph.
- `files/`: Contains PDF versions of:
  - `CV_Humberto_Bernal.pdf`
  - `Job_Market_Paper_Bernal_2026.pdf`
- `_config.yml` & `_pages/`: Source files ready to deploy on **GitHub Pages** using Jekyll.

## How to Deploy to GitHub Pages (zhumber.github.io)

1. Create a new repository on GitHub named `<your-username>.github.io` (e.g., `zhumber.github.io`).
2. Fork or clone [academicpages.github.io](https://github.com/academicpages/academicpages.github.io).
3. Copy the contents of this folder (`_config.yml`, `_pages/`, `images/`, `files/`) into your repository.
4. Push to the `master` or `main` branch.
5. GitHub will automatically build and publish your site at `https://<your-username>.github.io`!
